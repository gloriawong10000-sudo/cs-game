# 來源與素材 provenance

本專案 Remix 以使用者指定的 GameDev Showcase「Iron Rift FPS」完整遊戲原始碼、素材及設定 ZIP 為起點：

<https://d1oupeiobkpcny.cloudfront.net/assets/dashboard/materials/2026/10/01/91a314041a7bc265f7b27e13de622bb2a0f93f179e61a57185182ec1fb761d32.zip>

來源程式與執行素材已整合至 Riftline 專案的 `src/`、`public/assets/`、`scripts/`、`tests/`、`docs/` 等目錄，並保留初始化專案的 Three.js/WebDev runtime 整合。此專案以《Riftline: Breach Protocol》為新標題；繁體中文 UI 與新分享品牌素材位於主要專案目錄。

`iron-rift-share/` 只保留原來源的 favicon 和 OG 封面，供來源對照；目前遊戲不使用這兩張舊品牌圖作為作用中的 favicon 或分享封面。原始 ZIP 未在此重複複製。若要再散布來源素材，請依來源 ZIP 中的說明、授權與資產歸屬文件確認使用條款。
